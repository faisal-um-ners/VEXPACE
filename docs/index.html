The toolkit

Research-grade methods.
Human-friendly workflow.

Build a model visually, refine the right regions and investigate the underlying physics. From simple diodes to electromagnetic vacuum devices.

▦
01 / INTERFACE

Visual model builder

Create geometry, set boundary conditions, configure emitters and study settings. Inspect fields, live diagnostics and output without writing a solver.

⌗
02 / ELECTROSTATICS

Adaptive spatial resolution

scikit-fem finite elements with graded meshes and local 2D triangular refinement for near-emitter physics. Local meshes are fixed during each PIC run.

≈
03 / ELECTROMAGNETICS

Yee FDTD PIC

Charge-conserving deposition, wave excitation, laser sources, TEM ports and electromagnetic field evolution on uniform Cartesian or RZ grids.

↗
04 / PARTICLES

Established pushers

Boris, Vay and Higuera–Cary momentum pushers, with energy- and momentum-conserving field-gathering options.

✺
05 / EMISSION

Emission physics

Space-charge-limited, Fowler–Nordheim, thermionic, photoemission and prescribed beam injection from segments or surfaces.

≋
06 / WORKFLOW

Diagnostics & parallel runs

Current monitors, probes, field snapshots, phase space, parametric sweeps, Numba threads and optional MPI particle decomposition.

Precision where it matters

Resolve the fine structure.

Near emission edges and virtual cathodes, resolution matters. VEXPACE supports full-axis graded electrostatic meshes and conforming local P1 refinement on rectangles and polygons.

  • Local refinements for electrostatic PIC
  • Controlled transition and safety buffer

Get up and running

Install.
Build. Explore.

VEXPACE requires Python 3.9 or newer. Install the graphical interface from source, open an included example, and launch a simulation. Numba compiles kernels on first use.

Read the full guide →View source ↗
Terminal · macOS / Linux / Windows
# 1. Clone the repository
git clone https://github.com/faisal-um-ners/VEXPACE.git
cd VEXPACE

# 2. Install the GUI and dependencies
python -m pip install -e ".[gui]"

# 3. Launch VEXPACE
python -m picstudio gui
